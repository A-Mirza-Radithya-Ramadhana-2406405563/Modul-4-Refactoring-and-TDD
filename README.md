### Module 04 Reflection

1. Refleksi terhadap alur TDD berdasarkan Percival (2017)
   Secara keseluruhan, alur TDD yang sudah saya kerjakan dalam tutorial ini cukup membantu.
   Dengan menuliskan tes terlebih dahulu, saya menjadi paham akan requirement dengan lebih jelas. Saya juga bisa mendeteksi edge case lebih awal.
   Flow pengembangan RED-GREEN-REFACTOR memberikan struktur pengerjaan yang jelas, sehingga prosesnya teratur dan mudah untuk diikuti.
   Meskipun membantu, menurut saya masih ada hal yang dapat diperbaiki, seperti cakupan tes yang kurang untuk skenario yang lebih kompleks.
   Untuk pengembangan selanjutnya, saya perlu membuat lebih banyak negative test cases.
2. Refleksi terhadap prinsip F.I.R.S.T
   Saya dapat menyimpulkan bahwa tes yang saya buat sudah mengikuti prinsip FIRST.
   Meskipun demikian, saya tetap merasa bahwa masih ada ruang untuk perbaikan.
   Dari segi kecepatan (Fast), test sudah berjalan dengan cepat. Untuk independent, saya telah menggunakan fungsi setUp yang membuat setiap tes memiliki data yang baru.
   Test yang saya buat juga sudah Repeatable karena menggunakan data tetap tanpa bergantung pada faktor eksternal. Self validating juga sudah saya terapkan dengan menggunakan assertion pada setiap test.
   Hal yang masih perlu ditingkatkan menurut saya adalah aspek thorough. Menurut saya masih ada beberapa edge case yang belum tercakup dalam test ini.
   Untuk ke depannya, saya akan lebih teliti dalam mengidentifikasi case-case yang mungkin terjadi.
